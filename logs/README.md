# logs/

Holds `meal_log.csv` — generated by `src/app.py` (the "Log what you
actually ate" form), one row per logged day. Not manually edited; not
committed to git (personal usage data, see `.gitignore`).

## Schema

Every `actual_*` nutrition value is looked up from
`recipe_database/recipe_database.json` at log time (the recipe you select
in the dropdown) — never typed in or estimated, consistent with
`GOVERNANCE.md` HC-1.

| Column | Meaning |
|---|---|
| `date`, `logged_at_utc` | The day being logged, and when the entry was saved |
| `calories_burned`, `hunger_level`, `sleep_hours`, `workout_type`, `curry_type`, `curry_richness`, `meal_prep_time_min` | That day's context, as entered in the "Today" tab |
| `target_roti_count`, `target_protein_target_g`, `target_fibre_target_g`, `target_vitamin_focus` | Layer 1's prediction for that context |
| `recommended_recipe_name` | What Layer 2 (`recipe_agent.py`) recommended, if requested |
| `actual_roti_count` | Rotis actually eaten, typed in directly |
| `actual_recipe_name`, `actual_protein_g`, `actual_fibre_g`, `actual_vitamin_tags` | The recipe actually eaten (selected from the database) and its real values |
| `vitamin_match` | Whether `target_vitamin_focus` is in the actual recipe's `vitamin_tags` |
| `delta_roti_count`, `delta_protein_g`, `delta_fibre_g` | actual − target |

See `src/app_logic.py` for the code that builds and reads this file.
